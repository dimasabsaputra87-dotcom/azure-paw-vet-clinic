# Azure & Paw Family Veterinary Clinic

Static website for a family veterinary clinic in Bucharest. Plain HTML, CSS and JavaScript, no build step.

## Structure

```
index.html     page markup
css/style.css  styles
js/main.js     menu toggle, form validation, footer year
```

## Run locally

Open `index.html` in a browser, or serve the folder:

```
python -m http.server 8000
```
